Pengaturan AI

Studio tidak menyediakan AI. Sambungkan AI yang kamu punya.

Gemini API key

Ambil kunci gratis di aistudio.google.com/apikey

DeepSeek / OpenAI-compatible

DeepSeek: deepseek-flash + thinking disabled = ~2 detik, JSON valid. Thinking enabled membakar semua token untuk reasoning → jawaban kosong.

CLI langganan

CLI dipasang ke folder ~/.studio-isanovski/cli (tanpa sudo). Login memakai akun berlanggananmu sendiri.

OpenRouter API key

Buat key gratis di openrouter.ai/keys. Hanya model :free yang dipakai.
